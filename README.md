## About the Project

**A Little Game I Built with Phaser**

This was a fun and rewarding experience where I explored 2D game development using the Phaser framework. So far, I’ve implemented the following features:

### ✨ Features
- Smooth movement and jumping
- Melee attacks
- Defend / reflect mechanic
- Ability to throw shurikens
- Heal during combat

The game is a **2D side-scroller** with intense boss battles — perfect for quick play sessions!
